# 🎮 Android TV Remote - Quick Reference Card

---

## 📺 Channel Control

### 🔢 Direct Selection
```
┌─────────────────────────────┐
│  1  │  2  │  3  │  4  │  5  │
│  6  │  7  │  8  │  9  │  0  │
└─────────────────────────────┘
```
**চাপুন:** `1` → Channel 1  
**চাপুন:** `2` `5` → Channel 25  
**চাপুন:** `1` `0` `8` → Channel 108

### ⬆️⬇️ Navigate
```
        ↑
    Previous
    Channel
        
        ↓
      Next
    Channel
```

---

## 🎬 Player Control

| Button | Action |
|--------|--------|
| `SPACE` / `⏯` | Play / Pause |
| `F` | Fullscreen |
| `M` | Mute |
| `←` | -10 sec |
| `→` | +10 sec |

---

## 🧭 Navigation

| Button | Action |
|--------|--------|
| `ENTER` / `OK` | Channel List |
| `BACK` / `ESC` | Close / Exit |
| `Page ↑` | Previous Ch |
| `Page ↓` | Next Ch |

---

## 💡 Tips

✅ **Number appears on screen** when you press digits  
✅ **Notification shows** when changing channels  
✅ **2 seconds wait** for multi-digit channel numbers  
✅ **Wraps around** at end of channel list  

---

## 🆘 Not Working?

1. **Refresh browser** (Ctrl+Shift+R)
2. **Check if typing** in search box
3. **Try arrow keys** as alternative
4. **Open test page** to verify keys
