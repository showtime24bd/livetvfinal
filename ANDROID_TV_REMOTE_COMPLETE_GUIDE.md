# TV DEKHO LIVE - Remote Control Complete Guide

## 📺 Channel Controls

### Channel Up/Down
- **Channel + Button** → Next Channel (Up)
- **Channel - Button** → Previous Channel (Down)
- **D-Pad UP** → Next Channel
- **D-Pad DOWN** → Previous Channel

### Direct Channel Selection
- **Press 0-9 Numbers** → Type channel number
- **Wait 1.2 seconds** → Auto switch to that channel
- **Press Enter/OK** → Switch immediately
- **Large number shows in top-left corner**

Example:
- Press "5" → Shows "5" → Waits → Switches to channel 5
- Press "2", "5" → Shows "25" → Waits → Switches to channel 25

## 🎨 Quality & Display Controls

### Video Quality (if multiple qualities available)
- **Left Arrow** → Previous quality (High → Medium → Low)
- **Right Arrow** → Next quality (Low → Medium → High)

### Aspect Ratio
- **A Button** → Cycle through modes:
  - 16:9 (Default)
  - 4:3 (Classic TV)
  - Fill (Stretch to fill)
  - Fit (Best fit)

## ℹ️ Information Display

### Show Channel Info
- **Menu Button** → Display channel name & number
- **Info Button** → Display channel name & number  
- **OK/Enter Button** → Display channel name & number
- **Info auto-hides after 5 seconds**

## 🎯 Key Features

### ✅ What Works:
- All number keys (0-9)
- Channel +/- buttons
- D-Pad navigation (Up/Down for channels)
- Left/Right for quality switching
- A, Zoom In/Out, or Mode button for aspect ratio (cycles 16:9, 4:3, Fill, Fit)
- Menu/Info/OK buttons for channel display
- Smooth animations on all overlays

### 🚀 Auto Features:
- **Auto-start on TV boot** - App opens when TV turns on
- **Last channel memory** - Remembers last watched channel
- **Auto quality** - Selects best available quality
- **Auto-hide overlays** - UI elements hide after 5 seconds

## 📝 Notes:
- Channel overlay shows: Channel number + Channel name
- Number input overlay: Big number in top-left corner
- Loading spinner shows during channel switching
- Smooth fade-in/fade-out animations

## 🎨 Visual Indicators:
- **Blue glowing badge** - Channel number
- **White bold text** - Channel name
- **Blue border** - Number input box
- **Spinning loader** - Video loading
